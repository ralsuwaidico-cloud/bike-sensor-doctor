Checks (offline, on the real backup and in CI): no overlaps; app slots 64 KB-aligned; data 4 KB-aligned; everything inside 8 MB; one

store always open the partition labelled `nvs`, so giving that label to a new area is what guarantees Cyclift never writes the factory
settings.

## 4. How OTA selection works with the factory app (ESP-IDF bootloader)
The bootloader reads both OTA records, takes the valid one with the highest sequence number *s* and boots slot `(s−1) mod N`, where N is
the number of OTA app slots in the table. Today N = 1 and the records hold seq 1 and seq 0 → app0. With the new table N = 2: record seq 1
alone still means app0 (so writing the table alone does not change what boots); writing seq 2 into the older record (sector 0xF000)
selects app1, while sector 0xE000 (seq 1) stays untouched. Switching back = putting the original 0xF000 sector back.

## 6. Rollback and USB recovery procedure (proposal — every write step needs separate approval)
Preconditions: T-U2T on COM4; esptool 4.8.1; backup fingerprint re-verified; `plan_pieces` manifest re-verified.
Install order (if ever approved) — the "switch" is last, so an interruption before it leaves the factory app selected:
1. write Cyclift app at 0x400000 → `verify_flash`;
2. (only if S2 requires it) write planned sectors 0x1000 and 0x5000 with `--flash_mode keep --flash_freq keep --flash_size keep`
   → `verify_flash`;
3. write planned 0x8000 → `verify_flash`;
4. write planned 0xF000 (the switch) → `verify_flash`; reset.
Never `erase_flash`; never `--erase-all`; never write eFuses.

Recovery levels:
* **A — back to factory app in seconds:** write `original_0x00f000.bin` at 0xF000. The factory app boots (under the new table, with
  default settings; its own settings stay untouched in nvs_fac).
* **B — exact factory state of the first 4 MB:** write the original 0x1000, 0x5000, 0x8000, 0xF000 sectors; `verify_flash` each; read
  0x0–0x3FFFFF back and compare with the backup (the settings sector may differ only by the factory app's own drift, §1).
* **C — complete restore:** `write_flash 0x0` the 8 MB backup; read all 8 MB back; SHA-256 must be `77ad7105…3767693`.
* **If nothing boots:** the ESP32 ROM loader is permanent and download mode is enabled (eFuses unchanged) → B or C over USB.
  Automatic reset via the T-U2T worked every time; fallback = hold BOOT while pressing RESET.
