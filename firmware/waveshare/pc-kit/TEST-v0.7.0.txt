BikeComputer firmware 0.7.0 + iPhone app 0.8.0 — combined hardware checklist (26 Oct 2026)

0.7.0 = 0.6.1 (touch-wake fix, Settings layout) + pairing repair (new Bluetooth identity after a forget/data reset, stale-key
detection with a REPAIR action, diagnostics), profile-sync hardening (field checks, last-sync time, survives restart), the

Order: install the firmware first (section I), then the TestFlight build (0.8.0), then the tests. Board on USB, battery
DISCONNECTED (HW-1: never USB and battery together).

I. Install and recovery
 I1  INSTALL-v0.7.0.bat: finds the COM port, reads the 16 MB backup, says "Backup verified: 16 MB, firmware 0.6.1" (or 0.6.0
     rev N / 0.5.0 — whatever is on the board), asks YES, writes 2 regions, "INSTALLED". Board restarts to Home.   PASS/FAIL
 I2  Settings footer: "firmware 0.7.0" + build stamp. History lists your rides; the power meter is still paired.   PASS/FAIL
     Roll back any time: ROLLBACK-TO-v050.bat (0.5.0, keeps data) or RESTORE-BACKUP-BEFORE-v070.bat (exact image incl. data).
     Touch ever dead: RESET always works; SAFE MODE = hold BOOT while pressing RESET (touch gate off for that boot).

     templates from the previous build are still there.   PASS/FAIL

1. Pairing lifecycle (Rashed's ten points) — both devices together
 1-1  FRESH PAIRING. Board: Connections > Phone shows SEARCHING with TURN OFF (or REPAIR NEEDED: then hold REPAIR first).
      iPhone: Settings > Bluetooth: if "BikeComputer" is listed, tap (i) > Forget This Device. App: Connections > BikeComputer
      > Connect. Stages shown: Searching -> Found -> Pairing (6-digit code on the board) -> Authenticating -> Connected ->
      Syncing profile -> Ready. Board shows CONNECTED iPhone, Profile sync: synced hh:mm.   PASS/FAIL
 1-2  PAIRING AFTER A BOARD DATA RESET. Board: Phone > tap for details > HOLD: FORGET PHONE (this is what a data reset does to
      the bonds). Board shows SEARCHING, identity gen +1 (Details page). iPhone app: Connect. Expected with 0.7.0: the phone
      sees a NEW device and asks for the code again — NO "Peer removed pairing information". If the app instead shows the
      Repair screen, follow it (Settings > Bluetooth > Forget, then Connect) and note that here.   PASS/FAIL
      Also try the reverse: iPhone Settings > Bluetooth > Forget This Device while the board still remembers the phone; then
      Connect in the app: the board drops its old bond by itself and shows the code again (repeat pairing).   PASS/FAIL
 1-3  APP RESTART. Force-quit the app, reopen: it reconnects by itself within ~15 s, no code, board stays CONNECTED.   PASS/FAIL
 1-4  BOARD RESTART. Press RESET on the board: the app reconnects within ~20 s without touching the board (link enabled at
      boot). Profile sync shows synced again.   PASS/FAIL   (time: ___ s)

 1-6  OUT OF RANGE. Walk the phone ~20 m away (or Bluetooth off 30 s): app shows the link lost with a reason; board Phone

 1-7  AUTO RECONNECT. Come back / Bluetooth on: reconnected within ~15 s, no code, no touch on the board.   PASS/FAIL
 1-8  PROFILE SYNC. App: Profile > change weight by 1 kg and FTP by 5 W. Within ~5 s the board's Home shows the new FTP and
