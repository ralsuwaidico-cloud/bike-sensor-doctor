Proposal · onboarding flow

First-time setup, entirely on the device

About two minutes. Only what the coach needs is asked; everything has a sensible pre-filled value so a beginner can tap through. FTP and heart-rate zones are never asked: the starting FTP is estimated from weight and experience (the approved Android method) and the coach learns the rest from real rides.

Question 1 · navigation

How do you move around the device?

Matters most while riding: big targets, no accidental taps, always one gesture back to the dashboard.

RECOMMENDED

A · Ride pages carousel

+ Swipe left/right between Dashboard, Coach, Graph, Workout
+ Swipe down for sensors, brightness, battery
+ Pause/End need a 1-second hold, so a bump can't stop a ride
− Pages are found by swiping, not seen all at once
tap the dots or the screen edge

B · Circular hub menu

+ Everything visible around the ring
+ Natural on a round screen
− 6 small targets near the edge, harder with gloves
− An extra tap to get back to riding

C · Watch-style list

+ Familiar from smartwatches
+ Scales to many settings
− Vertical scrolling while riding is fiddly
− Little room per item on a 32 mm screen
Question 2 · numbers (age, weight, height)

How should numbers be picked?

Each starts pre-filled (age 35, weight 75.0 kg) so most people move it only a little. Weight steps in 0.5 kg.

RECOMMENDED

A · Spinning wheel

+ Large centre number, flick to move fast
+ Works the same for age, weight and height
− Needs a vertical swipe on a small screen
drag or scroll the wheel

B · Edge dial

+ Uses the round edge like a watch bezel
+ Whole range in one sweep
− Precise 0.5 kg steps are hard with a finger alone (− / + added)
drag around the ring

C · − / + buttons

+ Biggest targets, very precise
+ Hold to repeat
− Slow for large changes (e.g. 35 → 62)
tap or hold − / +
Question 3 · rider name

How should a name be typed on a round 32 mm screen?

A full 26-letter keyboard would give keys about 3 mm wide, too small for a fingertip (≈7 mm). These options keep every key at least 6 mm.

RECOMMENDED

A · Letter groups around the ring

+ Made for a round screen: tap a group, then the letter
+ Large keys; two taps per letter
− Takes a few seconds to learn
try typing your name

B · Paged keyboard

+ Looks like a normal keyboard
− Nine letters per page; swipe pages to find the rest
− Corner keys sit close to the round edge
swipe ‹ › to change page

C · Type it on a phone (optional extra)

+ Fastest if a phone is nearby: the device shows a QR code and serves its own setup page
− Needs a phone, so it can only be an extra, never the only way
Question 4 · main riding dashboard

What does the ride screen look like?

Power is the main number (as on the Nokia Power Focus). Works without a heart-rate strap: HR shows NO STRAP. Values below are a simulated preview.

RECOMMENDED

A · Power Focus

+ Watts as large as the screen allows (≈ 9 mm digits)
+ Outer ring shows power against the target band
+ One-line coach at the bottom
− Cadence and HR are smaller

B · Three gauges

+ Power, cadence and HR equal, like Classic on the Nokia
− Each number only ≈ 4 mm high: hard to read at speed

C · Minimal, swipe for more

+ Huge watts, nothing else to read
− Cadence/HR need a swipe; coach shows only when it speaks
