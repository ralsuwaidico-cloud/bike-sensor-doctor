## Integration gaps found (resolved inside the current architecture)
1. Train now / ride Start / strength Start did not check health holds — HomeModel + HealthHoldSheet, checks in ContentView, RideView, StrengthWorkout (Home B milestone).
2. Missed sessions had no status and past sessions could not be moved — derived "missed" + Store reschedule to a free day with Undo (Home B).
3. One recorded ride completed every planned ride that day — attribution to one planned ride, with test (Home B).
4. Weekly totals counted extras as planned-done — WeekTotals plannedDone/extra, same wording on Home, Plan, Progress (Home B / N1).
5. Sessions marked done without details led to an empty result — "Add details" to the existing log sheets (milestone 3).
6. Coach evidence counts are not stored — show the engine's own reason sentence only (no new engine fields in this project).
7. Rest days had no guidance destination — RecoveryGuidanceSheet (static, honest text) (Home B).
